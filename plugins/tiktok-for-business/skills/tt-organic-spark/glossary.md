# 术语对照：文件里怎么写，对商家怎么说

| 文件里 | 对商家说 |
|---|---|
| Spark Ad / 加热 | 把你已经发的帖子直接当广告投，广告显示的是你的账号和原帖，点赞评论都算到原帖上 |
| 广告授权 / authorization code | 允许广告账户使用这条帖子的开关，开了会生成一个授权码，有有效期 |
| 身份 / identity | 广告以哪个 TikTok 账号的名义展示 |
| Business Account | 商家账号，能看被 @ 数据和更多分析 |
| Video View / ENGAGED_VIEW | 按"看完 6 秒"优化的广告 |
| Engagement / FOLLOWERS / PAGE_VISIT | 按涨粉或进主页优化的广告 |
| CPV / CPM | 每次观看 / 每千次展示的价格 |
| 互动率 | (点赞 + 评论 + 分享) / 播放 |
| 完播率 | 看完整条的人占比 |
| 触达 / reach | 看到过的人数（去重） |
| 流量来源 / impression_sources | 推荐页、关注页、搜索、主页各带来多少播放 |
| 被提及 / mention | 别人发帖或评论时 @ 了你的账号 |
| 品牌 hashtag | 你开通追踪的 hashtag，能看带它的帖子 |
| 商用音乐库 / CML | 预先授权、发帖和广告都能用的音乐 |
| 暂停建 / DISABLE | 先建好不投，你看过再开 |
