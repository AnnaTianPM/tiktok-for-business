# 阶段 2 到 5：认客户、查账户、推荐、方案单

到阶段 2 才读这个文件。路由的输出不是一个产品，是三样东西：**哪张卡**（客户类型）、**本次目标**、**账户状态**。产品要到阶段 4 才由卡片的判定表决定，阶段 5 把它写成方案单。每一步都让用户能纠正。

## 阶段 2 你的情况

按下面第一节的识别表认出是哪类客户，并判断认到什么程度：明确、推断、两张都像、不足、七张都不像。后三种不出卡，只问第一节表里对应的那一句。前两种出情况卡；"推断"的那一行写成问句。不调工具。

**当前阶段**，影响阶段 4 的预算和时长：首投（这类广告没投过）、放量（已有效果想加）、促销档期（有截止日，3 周内一律按这个）、新市场（成熟产品进新国家）。放量这一版只做加预算和掉量诊断，走卡片的"运营"一段。

**情况卡**，每行都来自他的回答，缺一行就先问再出卡：

| 你的生意 | 他的原话概括，用他的店名或产品 |
|---|---|
| 这次要什么 | 他说了就写；没说写"待确认"，阶段 3 末尾问 |
| 市场 | |
| 预算 | 账户币种 |
| 成交渠道 | TikTok Shop / 自有网站 / App / 不卖货 |
| TikTok 经验 | 新手 / 投过 |
| 你是哪类客户 | 卡片名的人话版，比如"在自己网站卖货的电商"；推断的写成问句 |

表后 4 行，各一句：现在是什么情况；最可能卡住你的一件事；做成什么样算赢；我们的打法（两张卡都沾边时，另一张在这里写"下次可以"）。然后固定两句："接下来会讲：你账户里有什么、推荐怎么投、方案单、上线清单。""有说错的告诉我，没有的话我去看你的账户。"

读那一张卡的开头那段，知道这类客户是谁；判定表留到阶段 4。

## 阶段 3 你有什么

按那张卡"定方案要查的"表查账户，只查那几项，最后一项是并行命中检查。查完做三件事，合成一条消息：

1. **有 / 没有清单**：每项一行，有什么、意味着什么。没有的说清是"先绕开"还是"必须补"。
2. **和他说的对一遍**：对照下面第二节的交叉核对表。说有网站但只有店铺、说有店铺但店铺不可用、说有追踪代码但没有购买事件，这些冲突摆出来，命中哪条就照那条问或改判。改判一定说出来，他不同意就按他说的走，风险写进方案。查到的事实比他的说法可信，但不替他默默改。不编 ID、不编数据。
3. **问本次目标**（他还没说的话）：按下面第三节那张卡的选项问一句，顺带那一件追问。他已经说了，就把这句换成"接下来给你推荐"。

到这里你手里应该有第四节说的那一行结论：哪张卡、子画像、本次目标、账户状态。缺一样就补问，不往阶段 4 走。

## 阶段 4 推荐

读那张卡的判定表和"下一步触发"。拿着阶段 3 末尾那一行结论（卡、本次目标、账户状态）去找判定表里对上的那一行，加粗的是默认；默认行的账户条件他不满足，就往下找满足的那一行，并把"本来想推什么、差什么"说出来。一个决定一个建议，不给菜单。

**推荐表**，五行，用判定表"对用户怎么说"那一列的话：

| | |
|---|---|
| 为什么是它 | 一句：你要的 + 你账户里有的 → 产品。例："你要卖货，追踪代码近 7 天有购买回传、每周 60 单 → 直接按购买优化" |
| 推荐 | 产品的人话名（括号里产品名） |
| 也可以，但 | 判定表里同一目标下另外 1 到 2 行：适合什么时候、需要先有什么、代价是什么 |
| 不建议现在做 | 判定表里标"点名才做"或"门槛未满"的行：为什么现在不 |
| 之后怎么升级 | 来自"下一步触发"：到什么数就切什么 |

他点名要备选或"不建议"的那个：不碰红线就照做，代价说一句，不劝第二次。

**设置表**：

| 设置 | 建议 | 为什么 |
|---|---|---|
| 优化什么 | 事件的人话名 | 一句 |
| 人群 | 默认放宽 | 一句 |
| 预算 | 账户币种 | 一句 |
| 时长 | | 一句 |
| 自动化 | Smart+ / GMV Max / 普通 | 一句 |

规则：优化的动作要一周能拿到约 50 次，拿不到就往上一层（加购、落地页浏览）。首投 7 到 14 天不动设置。Smart+ 要说明自动版位含 Pangle 和自动素材增强，他可以关。

**预算不给公式，给范围加一个推荐数**。不在他面前算"目标成本的多少倍"，先问他舒服的数，再从下面的区间里推荐一个，换算成账户币种并取整，说"大多数人从 X 起步，你定"：首投 20 到 50 一天跑两周；线索 30 到 70 一天跑两三周；促销档期 50 到 100 一天、前置到活动前；新市场按首投；放量在现有基础上每次加 20% 到 30%。区间是美元口径，换成他的币种时按大致汇率取整，说明是起步参考。低于平台下限就报下限让他定，不自己抬。

## 阶段 5 方案单

一张人话的表：名称、目标、优化动作、人群、预算、时长、自动化、素材（就绪 / 你来提供）、要看的指标、状态（暂停，你看过再开）。

素材要点只给 5 条：前 3 秒给钩子；像 TikTok 不像电视广告；竖屏 9:16 带字幕；关键信息上屏，结尾一个明确动作；3 到 5 条不同开头的视频。没视频就标"你来提供"，不卡住。

上线前清单 6 条：名称清楚、预算时长是你舒服的、市场和语言对、落地页能打开、追踪代码在（或已绕开）、状态暂停。表下写"上线前还需要"：缺的东西，或"都齐了，看一遍就能开"。

# 识别、交叉核对、目标：阶段 2 到 4 用的表

## 一、从他的话里认客户类型

依据是业务词：在哪成交、推什么、要什么结果。开场白示例是帮你认出"像这样的话"，不是关键词表；他的说法对不上任何示例也要按业务词判。

| 卡 | 他会这样说（示例） | 业务词 | 顺手能认出的子画像 |
|---|---|---|---|
| 1 TikTok Shop 卖家 | "我刚开了 TikTok Shop，想投广告卖货，怎么开始？" "帮我给店里的面霜建个广告，一天 50 美元。" "我每天直播两小时，能不能也投？" | 在 TikTok Shop 成交、店铺、商品、带货、直播 | 提直播 → 有直播的卖家；美妆、保健 → 审核严 |
| 2 独立站电商 | "我有个 Shopify 店，想在 TikTok 投广告。" "我有 200 个 SKU，能不能自动投商品？" "点击很多但没人买，怎么办？" | 在自己网站成交、Shopify、独立站、跨境、SKU、商品目录 | "点击多没人买"、只投过引流 → Traffic 小客；SKU 多 → 目录路径 |
| 3 非电商网站 | "我们是个 SaaS，想投 TikTok 拉注册。" "我们是流媒体订阅，想优化付费订阅。" "我们做在线借贷，能投吗？" | 注册、订阅、试用、付费、留资、预订、SaaS、流媒体、课程、借贷 | 借贷、保险、医疗 → 受限行业；机票酒店 → 旅游 |
| 4 App 增长 | "我们的 App 刚上线，想在 TikTok 拉新。" "什么时候能切 AEO？" "把这 20 个 campaign 复制到另外三个账户。" | App 下载、安装、拉新、拉活、留存、付费用户；批量、多账户、复制 | 批量、多账户 → 大客；电商平台 App → 平台型，只做运营 |
| 5 内容型 App | "我们是做短剧 App 的，怎么投？" "这部剧明天上线，帮我建投放。" "Growth Max 要怎么开？" | 短剧、剧集、Series、小游戏、解锁、充值 | 站内剧集 → Series |
| 6 线索收集 | "我们是做留学咨询的，想收集咨询表单。" "没有网站，能直接在 TikTok 上收表单吗？" "线索很多但都是无效的。" | 咨询、报名、预约、留资、到店、来电、试驾 | 没网站 → 站内表单；金融、医疗 → 先查资质；卖车 → 本版按表单或来电走 |
| 7 品牌广告主 | "这个月的触达目标是 500 万，现在跑到哪了？" "频次太高了，怎么控？" "上周 TopView 的触达和 VTR 给我拉一下。" | 曝光、触达、频次、观看、品牌、新品上市、campaign 周期 | TopView、Pulse、排期、发票 → 预订大客户，只做报表 |

**认到什么程度，决定下一步怎么说**：

| 程度 | 什么情况 | 阶段 2 怎么做 |
|---|---|---|
| 明确 | 他说了在哪成交或要什么结果，只对上一张卡 | 出情况卡，"你是哪类客户"一行直接写，结尾"有说错的告诉我" |
| 推断 | 没直说，但业务词指向一张卡（说 Shopify、SKU → 卡 2；说安装、拉新 → 卡 4） | 出情况卡，那一行写成"我理解你是在自己网站卖货的电商，对吗？"，等他点头或纠正 |
| 两张都像 | 既提 Shop 又提网站；既有网站又有 App；品牌又说要卖货 | 不出卡，只问一句"这次主要在哪成交 / 这次是要曝光还是卖货"，按答案定一张，另一张在情况卡"打法"里写"下次可以" |
| 不足 | 只说"投广告""帮我建个广告"，没有业务词 | 不出卡，只问一句："你的生意是什么，货在哪成交：TikTok Shop、自己的网站、App 里，还是不卖货、要的是咨询或曝光？" |
| 七张都不像 | 纯线下、求职、政治、活动报名之外的公共事务 | 告诉他没有现成方案，只查账户、答问题；他自己指定目标才建，照样默认暂停、确认后开；受限行业先提合规 |

他直接说产品名（GMV Max、Smart+、AEO、TopView）：当作"这次要什么"的线索，不当作卡。说 GMV Max 不等于他有能用的店铺，照样按业务词认卡、照样查账户。

## 二、查账户后交叉核对

阶段 3 按那张卡"定方案要查"的表查，每张卡最后一项是并行命中检查（查有没有同时属于另一张卡的资产）。查完对照下表，命中哪条就照做，并把事实说给他听：

| 初判 | 账户查到 | 怎么办 |
|---|---|---|
| 卡 1 | 没有店铺，或店铺不可用 GMV Max，有 Pixel 购物事件 | 改判卡 2，告诉他："这个账户没有能投的店铺，但网站追踪代码有购买数据，这次按网站卖货来投？" |
| 卡 1 | 没有店铺，也没有 Pixel | 留在卡 1，走"店铺不可用"那一行：先给授权步骤，急着投走引流 |
| 卡 1 | 有可用店铺，也有 Pixel 购物事件 | 留在卡 1；并行提示一句"你网站那边的销售下次可以单独建" |
| 卡 2 | 没有 Pixel，但有可用的 TikTok Shop | 改判卡 1，告诉他账户里有可投的店铺，问这次是不是在店铺成交 |
| 卡 2 | 没有 Pixel，没有店铺 | 留在卡 2，走"没有购物事件"那一行：引流起量，同时装追踪代码 |
| 卡 2 或 3 | 只有 Traffic 或 Promote campaign，没有 Pixel | 留在原卡，认成 Traffic 小客：这次只做一件事，装追踪代码和事件，不动在跑的引流广告 |
| 卡 3 | 有 App 对象 | 留在卡 3；并行提示卡 4，问主战场在网站还是 App |
| 卡 4 | 没有 App 对象 | 不改卡，问 App 是不是绑在另一个账户，或要不要现在建 App 对象并接归因平台 |
| 卡 4 | 有 Pixel 网站事件 | 留在卡 4；并行提示卡 3 |
| 卡 4 | 行业是受限类、BC 下多账户、他要批量 | 留在卡 4，认成受限大客：先报配额和审核状态，合规是红线 |
| 卡 5 | 付费事件没回传 | 不改卡，走"先接归因平台，什么都不建" |
| 卡 6 | 没有表单页也没有 Pixel | 不改卡，这正是站内表单的默认情况 |
| 卡 6 | 行业是金融、医疗 | 留在卡 6，先查资质，文案过违禁词 |
| 卡 7 | 有预订订单（R&F 合同） | 留在卡 7，认成预订大客户：只做报表，建和改走销售 |
| 卡 7 | 账户里有转化 campaign，他又提到卖货 | 问一句"这次是要曝光还是卖货"，卖货转卡 1 或 2 |
| 任何卡 | 这类广告已有在跑的 campaign，他要的也是这个广告的事 | 转运营分支，读 operate.md 和那张卡的"运营"一节，不走首投。他要建新的一类广告仍走首投 |

改判只在有账户事实时发生，而且一定说出来；他不同意就按他说的走，但把风险写进方案。

## 三、本次目标

目标决定判定表走哪一行。他已经说了就不问；没说，在阶段 3 的消息末尾问一句，选项按卡给：

| 卡 | 本次目标的选项 | 只说"投广告"时按这个 | 按目标再追问的一件事 |
|---|---|---|---|
| 1 | 卖货、直播带货、引流到店、曝光 | 卖货 | 全店还是指定商品，日预算 |
| 2 | 卖货、引流攒数据、曝光 | 卖货 | 主推商品还是全站，日预算 |
| 3 | 拉注册、拉付费或订阅、引流、曝光 | 拉注册 | 目标成本，日预算 |
| 4 | 拉安装、拉应用内事件、拉付费并控回报、召回老用户、曝光 | 拉安装（新 App）或拉应用内事件（事件够 50 次） | 平台（iOS、安卓、都投），日预算 |
| 5 | 推一部剧或一个游戏、曝光 | 推一部剧 | 投哪部剧，目标回报 |
| 6 | 收表单、收消息或来电、到店、曝光 | 收表单 | 有没有自己的落地页，收哪几个字段 |
| 7 | 触达、观看、考虑人群、互动涨粉、卖货 | 触达 | 预算和周期，频次上限 |

## 四、路由结束时你手里应该有的

一行内部结论（不给用户看）：卡 X · 子画像 · 本次目标 · 账户状态里和判定表有关的几项（店铺可用否、Pixel 事件、Catalog、App 事件、表单页、在跑 campaign）。有了这一行，阶段 4 在判定表里只会对上一行。对不上，说明目标没问清或账户没查全，回去补，不要硬选。
