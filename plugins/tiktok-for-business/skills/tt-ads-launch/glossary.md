# 术语对照：文件里怎么写，对广告主怎么说

左列是卡片和参数文件里的写法，右列是说给广告主听的话。第一次提到用右列，后面可以带括号写缩写。

| 文件里 | 对广告主说 |
|---|---|
| Pixel | 网站的追踪代码（Pixel），用来知道谁买了、谁加购了 |
| 事件 / optimization_event | 追踪代码记录的动作：浏览、加购、购买、注册 |
| Website Conversions / 转化广告 | 按网站上的购买（或注册）优化的广告 |
| Web Traffic / LPV | 先把人引到网站的广告，用来攒数据 |
| Catalog | 商品目录，Shopify 等平台可以自动同步 |
| GMV Max | TikTok Shop 的自动卖货广告，系统自己选商品和视频 |
| Smart+ | 自动投放模式，系统自己定人群和版位 |
| MAI | 按"装 App"优化 |
| AEO | 按"App 里的动作"优化，比如注册、付费 |
| tROAS / VBO / HV | 按花一块钱赚回多少优化；HV 是不设目标、尽量赚最多 |
| MMP | App 的归因工具，比如 AppsFlyer、Adjust，用来把安装和付费回传给 TikTok |
| SKAN | 苹果的隐私归因方式，iOS 14.5 以上要用 |
| Instant Form | TikTok 站内的表单，不用自己做网页 |
| Web Form | 自己网站上的表单 |
| CPL / CPA / CPI | 每条线索、每次转化、每次安装的成本 |
| ROAS | 花一块钱带来多少销售额 |
| Lowest Cost | 不设出价，让系统用最低成本拿结果 |
| 学习期 | 刚开的广告头 7 天或前 50 次结果，系统在摸索，不要改设置 |
| Reach / Video View | 按"多少人看到"或"多少人看完 6 秒"优化的品牌广告 |
| R&F / TopView / Pulse | 预订制的品牌广告，走销售签合同，不在后台自助建 |
| 暂停建 / DISABLE | 先建好但不投，你看过再开 |
