# 术语对照：文件里怎么写，对品牌怎么说

| 文件里 | 对品牌说 |
|---|---|
| TTO / TikTok One / Creator Marketplace | TikTok 官方的达人合作平台，找达人、建活动、拿授权都在这 |
| TTO 账户 / tto_id | 你在 TikTok One 上的品牌或代理账户 |
| 品牌档案 / Brand Profile | 达人看到的你的品牌页：名字、行业、logo、官网 |
| 活动 / campaign（TTO 的） | 一次达人合作项目，不是广告活动 |
| 邀请链接 / invite_link | 发给达人的链接，点开就能加入活动 |
| CAMPAIGN / 活动级链接 | 视频归到这个活动，可以只让受邀达人加入 |
| BRAND_LINK / 品牌级链接 | 任何达人都能把视频挂到你品牌下 |
| 挂链 / link | 达人把视频关联到活动 |
| Spark 授权 / authorization | 达人允许你的广告账户用他的视频投广告，有天数 |
| 自动授权 / advertiser_ids + 授权天数 | 活动绑了广告账户后，达人挂链就自动授权，不用再要码 |
| Anchor | 达人视频下方挂的网页链接按钮，只在没 TikTok Shop 的国家能用 |
| industry label | 达人接过哪类商单 |
| content label | 达人日常发什么内容 |
| 中位播放 / median_views | 他最近视频播放量的中间值，比平均稳 |
| engaged audience | 真正点赞评论分享的人的画像 |
| 起步价 / starting_price / creator_price | 达人公开的最低报价，0 是没公开 |
| 排行榜 / scoreboard | 美国达人按商单或自然内容表现的排名 |
| AUTH_CODE 身份 | 广告账户里代表这位达人的身份，建 Spark Ad 时用 |
| 暂停建 / DISABLE | 先建好不投，你看过再开 |
